How to Run the Project

Follow these steps to download and run the game:
1- Download and install Visual Studio 2022.
2- During installation, select the Desktop development with C++ workload.
3- Download the project ZIP file from release version.
4- Extract the ZIP file to your computer.
5- Open the extracted project folder.
6- Locate the .sln (Visual Studio Solution) file.
7- Double click the .sln file to open the project in Visual Studio.
8- Once the project has loaded, click the Local Windows Debugger button or press Ctrl + F5 to run the game.
9- Enjoy playing!

Troubleshooting / Additional Notes:
If the game does not run properly:
1- Set the Windows SDK Version to the latest available version in Visual Studio 2022 under Project Properties → General.
2- Make sure Visual Studio 2022 is updated to the latest version.
3- Check that all the required relative paths are correctly configured , especially under General and Linker properties.
4- Verify that the necessary library and include directories are set correctly.
